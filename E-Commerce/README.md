# 🛒 E-Commerce Website (React)

A modern and responsive E-Commerce Web Application built using **React.js**.  
This project provides users with a smooth online shopping experience including product browsing, cart management, search functionality, filtering, and responsive UI design.

🔗 **Live Demo:**  
https://sprightly-swan-f1810f.netlify.app/

🔗 **GitHub Repository:**  
https://github.com/chaitanyagomaskar25-art/E-Commerce_Website-react-

---

# 📌 Project Overview

This project is a frontend-based e-commerce website developed with React and modern web technologies.  
The application focuses on creating a clean UI, reusable components, responsive layouts, and smooth user interaction.

The website allows users to:

- Browse products
- Search for items
- Filter products
- Add/remove products from cart
- View product details
- Experience responsive shopping UI across devices

The project demonstrates practical implementation of React concepts such as:

- Component-based architecture
- State management
- Props handling
- React Hooks
- Routing
- Dynamic rendering
- API integration concepts
- Responsive web design

# ⚙️ Installation & Setup

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/chaitanyagomaskar25-art/E-Commerce_Website-react-.git
```

## 2️⃣ Navigate to Project Folder

```bash
cd E-Commerce_Website-react-
```

## 3️⃣ Install Dependencies

```bash
npm install
```

## 4️⃣ Start Development Server

```bash
npm run dev
```
