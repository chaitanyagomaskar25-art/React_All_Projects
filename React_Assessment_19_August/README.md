## Shopping Cart Prject
### Instructions to use my project
1. To start it use 'npm run dev' command
2. On home page it shows the product list of all products.
3. when user will click on add to cart button it will add it in cart.
4. when user will click on remove from cart button it will remove from cart.
5. when user will click view details it will show the details of product
6. user can navigate through navigation bar.
